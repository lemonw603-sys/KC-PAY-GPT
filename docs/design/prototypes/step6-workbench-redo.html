§1 · 三版都改掉了什么

  • 拆开那个塞了四样东西的卡片：营业开关、路线与卡台、发码，现在各是各的，不再共用一个无标题的方框。
  • 每块都有标题区（小标签 + 标题 + 右侧状态），和设置页一致；现在的工作台有几块是没有标题直接堆内容的。
  • 「待接入」不再占满一格大字：灰、小字、不可点，一眼能看出它不是一个数。
  • 待办给按钮：现在的队列只有文字和跳转，A/B/C 都把「去贴 token」这类动作摆在行尾。

§2 · 三版的取舍

  • A 按动线：从「要我处理什么」开始往下读，最贴你早上打开后台的顺序。代价：整页较长，卡与钱和日对账要往下滚。
  • B 左右分栏：操作全在左边固定一栏，看的东西在右边。代价：左栏在窄屏会被压到下面；两栏高度不齐时右边会留白。
  • C 状态头 + 网格：一屏塞得下最多信息，顶部一行说完「现在什么状态」。代价：开关变成「改开关」按钮弹出来改，不如 A/B 直接拨。

§3 · 数据

  • 取自本地 demo 库（4 单 / 两台各 1 张可分配 / token 失效告警），不是编的；「待接入」三格是真的还没做（D-284 ③ 与聚合未写）。
