# 定稿快照：卡片页 A「台账优先」（2026-09-20）

这三份 CSS 是 `step6-cards-a.html` 定稿那一刻，从 `v1/public/admin/assets/` 原样复制的。
**原型必须 link 这里的快照，不能 link 实时的实现样式**（`proto-server.mjs` 会把
`/admin/assets/*` 反代到跑着的后台——那条路会让参照物跟着被测物一起变，比对永远通过。
2026-09-20 营业条那次就是被变异测试当场拆穿的，见 `_frozen/opsbar-v5/README.md`）。

## 这一版冻的是什么

A 版（D-287，Lemon 从三版里挑定）的三块 + 一个高级入口：

1. 两台卡台并列（`.cardrigs`）
2. 在役卡片列表 + 历史折叠（`.cardtable` / `.cardfold`）
3. 待销清单（`.cardretire`）
4. 高级（`.cardadv`）——卡台管理 / 导入 / 两台开卡 / 补卡记录 / 新卡接管

**顺序按 A 版原型**：在役列表在待销清单**之前**。实现此前是反的，B 部分一并纠正。

快照里已含本轮为 B4 新写的 `.cardadv*` 与为 B1 搬迁新写的 `.cardgate`
（一律裸 `var(--wb-*)`、不加字面色回退，免得推高 `css-baseline.json` 的棘轮）。

## 什么时候更新快照

只有**重新定稿**时：出新原型 → Lemon 挑定 → 才重新冻。
日常改实现不更新——实现偏离快照正是要被抓出来的东西。
