# 备份与恢复验收基线

## 当前边界

- 备份账号为独立的只读账号，不复用应用账号、迁移账号或 root。
- 备份文件使用 AES-256-CBC + PBKDF2 加密，密钥单独保存在 `/etc/pojia/backup-key`，不进入项目目录。
- 备份目录权限为 root-only，保留期暂定 14 天。
- worker 和供应商写权限在恢复验证期间必须保持关闭。

## 上线前验收

1. 生成一份加密 SQL 备份并校验 SHA-256。
2. 解密并恢复到隔离数据库，不覆盖 `pojia` 业务库。
3. 对比迁移版本、表数量和 Session 密文列形态。
4. 删除隔离数据库和临时明文文件。
5. 配置异地加密副本；仅有本机备份不能视为灾备完成。
