# Browser 余额不足卡：付款前停止测试

## 目标

使用用户指定的测试 Session 和一张余额不足卡，验证 Browser 链路直到“订阅/付款”按钮前，不执行点击。

## 执行边界

1. 读取 Session 仅限隔离 Browser 运行时；不保存原文。
2. 核对账号登录、账号套餐、订单/产品为 Plus。
3. 核对卡片引用、余额状态、订单绑定和资金栅栏。
4. 打开 Checkout，确认金额、支付字段和唯一提交控件。
5. 允许填充后立即清理卡字段；最终停在付款按钮前。
6. 不点击订阅、不提交表单、不产生付款尝试。

## 输出

只记录脱敏结果：Session 摘要、账号/套餐判定、卡片尾号或 opaque ref、页面状态、资金栅栏、停止原因和时间。

## 失败处理

- Session/页面/卡资料在付款前失败：`PRE_SUBMIT_FAILED`，可修正后重试。
- 任何实际点击后的未知结果：`PAYMENT_RESULT_UNKNOWN`，禁止重付。
