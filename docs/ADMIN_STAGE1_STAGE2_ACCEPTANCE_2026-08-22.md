## Session 粘贴异常（用户截图）

截图中 Session JSON 末尾被追加了 `Chat-Memo Logo / 自动记忆` 文本。客户页当前对 textarea 全量执行 `JSON.parse`；尾部存在非 JSON 文本时，必然触发 Session 格式错误。这是输入内容被浏览器扩展污染的事实，不是 Session 校验器把合法 JSON 判错的证据。

当前安全处理：不要在服务端静默截断或清洗未知尾部内容；应先禁用该扩展在充值域名上的注入，或使用“粘贴为纯文本”并确认内容最后一个有效字符为 `}`。后续可增加前端错误提示，明确指出“输入包含 JSON 以外的附加文本”。
