- 客户自助提交 CDK 和 Session，系统开通目标套餐；运营不必逐单在场。北极星是一天几十到上百单。

- Plus 成功口径（用户定）：确认 Plus、关闭自动续费、内部核对完成后才显示成功；提前成功方案已撤回（D-240）。
