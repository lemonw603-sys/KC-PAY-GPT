## 2. 页面与规则

一条流水线：四格 → 生成条 → 筛选主表。批次列表删除，保留批次筛选和折叠导出。沿用候光令牌、原生JS/CSS，不换栈。

| 格子 | 唯一口径 |
|---|---|
| 待兑换 | AVAILABLE且未过期，普通/卡网投放或已登记发出的备码；不代表已售 |
| 应急备码 | AVAILABLE且未过期，明确RESERVE且issued_at为空；以后台登记为准 |
| 已成功交付 | REDEEMED且订单RECHARGE_SUCCESS |
| 要看一眼 | REDEEMED且订单RECHARGE_FAILED/CLOSED，COALESCE(finished_at,created_at)不早于2026-09-07 15:00 UTC |

- 列表另筛处理中、过期、作废、历史未分类；历史异常如实展示并带09-07前标记。
- 旧码用途记LEGACY，不能由空备注推成库存；不批量改旧码有效期。现有未发历史码不硬塞四格。
- 普通生成默认直接发码，备注选填，不另要求登记；生成/下载不证明实际收款或交付。
- 应急备码另选用途。客户在未补登记时先来兑换，受理时补issued_at，未付款失败退码后仍属待兑换，不回备码库存。
- 卡网用途选择时带出不过期，可明确改自定义；已投放码不在别处重复发。
- 有效期模式明确区分DEFAULT/CUSTOM/NEVER：不填自定义=生成时间+30天；NEVER=无到期日；时间显示/输入为北京时间。单张、批量一致。
- 已发出码只能延长期限或设不过期；过期可手动延期。不中断既有在途单，付款未知继续按原规则锁定，不加永久重试/自动延期。
- 数量大于1展开可选去向/批次总额/币种；单张可展开备注，金额仍归原订单付款记录。不卡必填去向。
- 生成即复制；复制失败保留结果框供手动复制；成功后自动清其他筛选并定位刚生成批次。不自动下载。
- 生成幂等覆盖所有业务参数。明确400校验失败允许改正；结果未知保留原键并提供恢复原参数按钮，不能换键重新生成。
- 表列：本页多选／完整卡密／产品／状态／去向／完整客户邮箱／最近动静／操作。
- 完整卡密走hash精确搜索；订单号、邮箱、备注可子串搜索，SQL过滤早于COUNT/LIMIT。搜索内容走受保护POST正文，不进URL。
- 多张批次点去向筛整批，单张去向不跳批次。批次选择分页加载，不将单张批次充满下拉。
- 最近动静含作废及管理操作时间。定时刷新主列表，不累加批次；有选择/输入/写操作时暂停自动刷新。

## 3. 批量/导出

- 全选明确仅本页，换筛选/翻页清选择。提交携带明确ID快照。
- 作废前确认数量；状态过时或含已绑定/已使用码整批拒绝，不能部分执行却笼统报成功。
- 所有选择的变更与审计在同一事务内；重试作废已作废码为无须再改。
- 取消“撤销已发出”，旧端点issued=false也拒绝。
- 备码补登记可不填备注；批次属性编辑是整批动作，不从部分码推断整批渠道或金额。
- 原始整批TXT只作留档，始终提示可能含已发出/已兑/作废/过期码；另有逐码状态CSV。
- 作废/改期等完成后隐藏旧生成结果，避免旧结果被误当新发货清单。
