# Browser 真实付款前检查清单

状态：代码与隔离测试完成；生产付款仍关闭。此清单不是付款授权。

## 必须满足

- [ ] 生产 `BROWSER_PAYMENT_EXECUTOR_ENABLED=false` 保持不变，模式为 `MOCK`，除非 Lemon 单独确认本单真实付款。
- [ ] 订单、attempt、资金锁、卡绑定和 Browser run 均为同一条权威记录；没有 UNKNOWN、重复提交或活动租约。
- [ ] 客户 Session 已通过现有只读检查，账号为 FREE 且目标套餐为 Plus；已确认不是已激活 Plus。
- [ ] Checkout 观察结果完整：URL、套餐、金额、支付表单、卡字段和唯一提交选择器均匹配；未发生提交。
- [ ] 卡台卡片资料和余额为最新只读证据，卡片未被其他订单占用；资金成本和风险可接受。
- [ ] LIVE 适配器门禁、结果观察器、取消自动续费观察器、Plus 激活观察器、卡台交易对账器均已在当前版本联调通过。
- [ ] 付款结果未知时只进入人工对账，不重付、不换卡、不换执行器。

## 付款后必须确认

1. Provider/Checkout 明确返回付款成功；
2. ChatGPT 账号 Plus 已激活；
3. 自动续费已取消并有可追溯证据；
4. 卡台交易金额、时间、卡片和订单匹配；
5. 订单最终状态与以上证据一致并写入审计记录。

任何一项无法确认，订单保持待对账，不得再次付款。
