# 证据矩阵（2026-08-23）

本文件纠正“已验证”一词的歧义。只有生产运行证据才称为“生产已验证”；代码和测试不等于生产资金链路已验证。

## 生产运行已验证

- Web/Worker、live/ready 健康检查；
- 客户提交 → CDK 兑换 → 订单创建 → 库存分配尝试 → Provider 明确失败 → 客户 FAILED（真实失败链路）；
- Plus 目标账号被 Provider 40030 拒绝；
- 后台订单查询支持 CDK、邮箱、账号 ID 等字段；
- 卡台余额/规则只读同步及卡目录只读同步；
- Session 尾部扩展文本自动整理，且不再显示附加文本提示；
- 客户页终态轮询；
- 接单、派发、Provider 写入门禁保持关闭。

## 代码与隔离测试已验证，但未做生产资金验证

- 卡余额充值账本、幂等栅栏、PENDING/UNKNOWN/MANUAL_REVIEW 状态；
- HNSKJ `rechargeCard()` 适配器；
- 自动补卡规划、每日上限和低库存调度；
- 卡余额充值只读对账 runner；
- 卡台替换/备用卡台的数据结构基础；
- 浏览器自动化充值控制面基础。

## 尚未验证

- 真实卡片余额充值写入；
- 真实自动开卡写入；
- 成功客户充值及取消自动续费完整链路；
- Provider 写入后的 UNKNOWN 恢复；
- 浏览器自动化真实充值；
- 全部后台页面的浏览器视觉逐页验收。

## 术语纪律

- 历史聊天中的“做过/验证过”只有在能对应到代码、测试输出、生产日志或数据库证据时才进入前两类；否则标为“历史说法，待核验”。
- 后续报告必须同时写明证据类型，不再笼统写“已验证”。
