# Pro 20X 基础准备复核｜2026-09-05

## 术语核对

本记录将用户所说“20X”按项目既有产品命名解释为 `Pro 20X`，不是 `Plus USD 20/月`。现有代码/文档已将 Pro 20X 作为后续产品预留，但当前 V1 业务只启用 Plus。

## 已有证据

- `products`、`fulfillment_routes`、CDK `plan_type` 已具备扩展字段。
- 当前 CDK 服务 `PLAN_TYPES` 只启用 `plus`；Pro 5X/Pro 20X 尚未进入生产路由。
- Browser Checkout 观察器已能读取实际产品、币种、金额、税费和总额，但这些值必须按实际 Checkout 重读，不能由产品名称或地址标签推断。
- 用户此前提供的 X 链接当前无法直接抓取（返回 HTTP 403）；不能把链接内容当作已核实事实。仓库既有报告仅能作为待复核线索。

## 建议

本次真实 Browser Plus 订单可以顺手完成“产品扩展准备”而不改变当前业务：

1. 保持订单、CDK、路线和观察器使用 `plan_type`，不写死 Plus 文案；
2. 为 Pro 20X 定义待启用的产品配置接口/显示位，但保持 disabled；
3. 测试结果记录实际 Checkout 的产品识别字段，确保未来更换产品时不会误把 Plus 当成 Pro 20X；
4. 不提前开放 Pro 20X CDK、不新增 Provider 路由、不做真实付款。

## 边界

Pro 20X 的真实价格、税费、资格、Provider 合同、退款/取消和付款结果目前均未验证。只有完成独立非付款观察并经单独产品验收后，才可启用该产品。
