## 已定业务（不再反复改）

1. 普通发码：客户需要时现生成复制，去向/备注/金额不强制；空备注不代表库存。
2. 应急备码：明确选用途，可备注、预存手机；离线发出在清单留记号，方便时回后台补登记。补登记不影响兑换。客户先用、无付款失败退码后不再算备码库存。
3. 卡网投放：主动选不过期，卡网销售发货；不接销售接口、不逐笔补销售记录，不重复投放到别处。
4. 默认期限从生成起30天；可自设、可手动延期、明确选不过期。不给历史码批量改期，不建自动延期/永久重试状态机。
5. 不撤销发出回库存，不做复杂拆批/多价结算；未使用码不要了走作废，付款未知仍按原规则锁定。
6. 四格＝待兑换／应急备码／已成功交付／要看一眼。前两格排除过期、在途、作废；待兑换不代表已售，备码数以登记为准。历史异常使用finished_at/created_at界线，不用updated_at。
