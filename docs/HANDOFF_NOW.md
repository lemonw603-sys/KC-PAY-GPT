   所有 `upsertBrowserAlert*` 都强制要 `orderId`（`browser-alert-repository.js:25`），
   告警体系是订单驱动的，所以"库存空了"必须等客户来撞一次才有人知道。客户那次会白等。

   (humanVerification is not defined)` 就是正在跑的 worker 加载了我改到一半的文件。
