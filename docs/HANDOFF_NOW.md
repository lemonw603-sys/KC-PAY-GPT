## 怎么做一页重做（走通两轮的顺序，照搬）

1. 出原型给 Lemon 挑 → 定稿
2. **冻 `_frozen/<页>/` 快照**（三份 CSS + README）
3. **写定稿原型**：link 快照、被量的树里零原型专属 class、**带全外壳**（`.admin-shell` 是 `230px + 1fr`，少了侧栏整页被压窄，卡片页因此报出 26 处假差异）
4. **先写契约再实现** —— 第一次跑必然红，这本身就证明它不是空的
5. 实现到绿
6. **变异测试**：故意改坏看契约报不报。抓不到的要么补探针，要么**如实标明盲区**

## 禁止 / 注意

- 开卡 / 补余额 / 充值 / 付款 / 退款 / 切路线 / **发布 / 应用迁移** / 改开关 / 重启常驻 worker / **作废那 21 张老码** 先开口问；不碰 browser-mvp（D-254）。
- **发布门槛三件**：外观符合选定方案 + 数据字段口径正确 + 按钮业务结果正确。测试数量 / HTTP 200 / SQL 有返回**都不算数**。
- **CSS 只许降不许升**（D-293）：新规则用裸 `var(--wb-*)`，不加字面色回退。
- **界面「像不像设计稿」不许用眼睛判**（D-292）：测量前先断言 `innerWidth`；放大只用 `transform: scale()`。
- **删代码按语法边界（配对大括号），不按字符串距离**（D-289）。卡片页那轮误删 14 个顶层事件绑定，**951 条测试全绿而侧边栏点不动**。
- **说「不存在 / 零引用」之前至少查三种形态**（按名字 / 按内容 / 按 git 历史）。本窗口靠它查清了 `expires_at` 无写入路径、CDK 页零测试覆盖、REBOUND 的产生点（在 `v1/scripts/` 里，只搜 `v1/src` 会漏）。
- **改 `admin.js` 后同步 bump `index.html` 里的 `?v=`**（本仓库惯例）。
- **「两处一致」不等于「两处正确」**（D-307 的教训）。CDK 页的「已交付」就是：接口与 SQL 完全一致，而两个口径互相矛盾。
- **界面上每多一句话，先问它对着的人能不能据此做点什么**（D-312 的教训）。任务书 §十列了要删的四句。
