# 网络级连接断开风暴对抗式审查（2026-08-22）

## 反证问题

1. **是否把容器 pause 当成网络分区？** 不是。本轮使用 MySQL `KILL CONNECTION`，结果反而暴露更窄的连接级失败。
2. **watchdog 是否掩盖成功？** 没有。watchdog 只把无界等待变成明确失败；没有生成 claim/heartbeat 成功数字。
3. **是否发生付款或重付？** 没有。Harness 只操作隔离 dispatch/订单夹具，付款动作仍为 0。
4. **是否能归因到 repository？** 不能完全归因。生产/清理仍直接使用 mysql2 `pool.query`，需要 repository-only 复验。
5. **是否可以进入本地 Browser 阶段？** 不可以。网络级连接恢复和连接池边界仍未关闭。

## 强制结论

- 当前阶段 1 不通过最终闸门。
- 不能宣称网络级重连、连接池耗尽或 24 小时 soak 已验证。
- 下一批必须先证明故障测试本身有界，再报告控制面指标；任何未知状态仍进入停止/对账，不允许重付。
