    如何获取账号 Session

    在浏览器登录要充值的 ChatGPT 账号，打开官方 Token 页面，把整段内容复制粘贴回来即可。两个按钮直达官方页面：

    请在浏览器依次打开
    chatgpt.com chatgpt.com/api/auth/session
    1. 1
      登录要充值的账号

      点「先登录 ChatGPT」，确认浏览器当前登录的就是本次要开通 Plus 的账号。

    2. 2
      打开 Token 页面

      点「打开 Token 页面」，浏览器会显示一段 JSON 文本（chatgpt.com/api/auth/session）。

    3. 3
      全选复制

      Windows 按 Ctrl+A 再 Ctrl+C；Mac 按 ⌘+A 再 ⌘+C，复制整段 JSON。

    4. 4
      粘贴回本页

      回到充值页，把完整 JSON 粘进「账号 Session」输入框，点「下一步」核对邮箱。

    正确页面示例（应包含 email、accessToken）
    {"user":{"id":"user-…","email":"you@example.com"},"accessToken":"eyJhb…","expires":"…"}

    Token 包含账号登录权限，请勿转发给他人；充值完成后建议退出 ChatGPT 再重新登录一次。
